## How to read the evidence labels

- **Original internship artifact:** an original report, screenshot, or source record found in the supplied materials. Original files remain private unless a separately identified derivative is published.
- **Sanitized evidence derivative:** a redacted/cropped copy that preserves the narrow technical observation while excluding unnecessary identifiers.
- **Independent reconstruction:** a later diagram or infrastructure source reasoned from retained material, not recovered as internship code.
- **Reproducible demonstration:** new local code or a test created for this portfolio.
- **Independently validated:** a stated check actually run; the command, environment, result, and limits are recorded.
- **Not established by retained evidence:** the materials do not support the claim.
