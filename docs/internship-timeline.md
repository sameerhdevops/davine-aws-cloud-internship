## Reading the labels

- **Original internship file (as described in repository notes):** an item identified by existing notes as originating in the internship source set; the private source was not checked in this pass.
- **Sanitized screenshot copy:** a published crop described as coming from an internship console image; its source match and redaction are not verified here.
- **Portfolio design based on project descriptions:** a diagram or configuration assembled from available descriptions, not a recovered internship source file.
- **Reproducible demonstration:** local code or a test included so a reviewer can run the described behavior.
- **Validated check:** a named command actually run, with environment, result, and scope recorded.
- **Not established:** the repository materials do not support the claim.
