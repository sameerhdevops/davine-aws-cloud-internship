# Project scope

This repository presents a 12-week AWS Cloud Engineering internship learning record and the TalentFlow AI capstone context, alongside small local engineering examples. Its purpose is to make evidence, assumptions, and reproducible checks easy to inspect.

## Included

- Twelve weekly narratives that separate reported portal schedule state, retained-material descriptions, and added portfolio work.
- Six deterministic Python demonstrations with standard-library unit tests.
- A read-only AWS API snapshot tool for selected EC2 resources and account-owned general purpose S3 buckets.
- A reconstructed Terraform baseline for a limited subset of networking, security, storage, IAM, logging, and monitoring resources.
- Diagrams that distinguish the proposed capstone architecture from the smaller declared Terraform configuration.

## Excluded

- The original capstone application and original infrastructure source, which are not in the tracked repository.
- AWS deployment, resource creation, modification, or teardown as part of repository validation.
- A complete IAM authorization evaluator, organization-wide governance engine, vulnerability scanner, or network reachability analyzer.
- Claims that all weekly assignments were submitted or accepted, that the capstone was deployed, or that a screenshot shows current AWS state.

## Boundaries for interpreting results

“Schedule completed,” “evidence retained,” “demo passed,” “Terraform validated,” and “resources deployed” describe different facts. See [Evidence and provenance](EVIDENCE.md) for the labels used throughout this repository and [Security notes](SECURITY-NOTES.md) for the AWS/API boundary.
