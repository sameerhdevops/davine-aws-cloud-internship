# AWS security, governance, cost, and monitoring

## Evidence status

**Cross-cutting evidence.** The material includes IAM, budget, Cost Explorer, Trusted Advisor, Well-Architected, and before/after remediation views.

## Topics represented

- IAM dashboard and least-privilege framing
- Budget and cost-explorer review
- Trusted Advisor and Well-Architected review
- CloudWatch alarm/monitoring evidence
- A documented before/after remediation concept: reducing public exposure, strengthening access controls, and improving governance

## Interpretation

These are historical review and learning artifacts. They should not be represented as a current cloud-security assessment or as proof that every recommended remediation remains in place.

## Publication decision

Screenshots are excluded because they show account/resource context and may contain sensitive infrastructure details. This documentation records the learning themes without copying those values.
