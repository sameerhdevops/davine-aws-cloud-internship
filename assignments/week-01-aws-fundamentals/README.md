# Week 1 - AWS fundamentals

## Evidence status

**Confirmed internship evidence.** A named Week 1 report documents exploration of IAM, EC2, S3, VPC, RDS, Lambda, CloudWatch, Route 53, CloudFront, and DynamoDB.

## Objective

Build foundational familiarity with the role of core AWS services and their place in a cloud environment.

## What the material supports

The report identifies identity and access management, virtual compute, object storage, networking, managed relational and NoSQL data stores, serverless compute, monitoring, DNS, and content delivery. Separate screenshots show console views for several of these services.

## Lessons captured

- Service selection depends on responsibility boundaries: compute, storage, networking, identity, databases, observability, and delivery are distinct concerns.
- Security controls such as IAM and S3 encryption/public-access settings require explicit review.
- A console view is a point-in-time observation, not a current-state audit.

## Limitations

Original report pages and screenshots are withheld pending publication review. The available material does not include reproducible configuration files or assignment instructions.
